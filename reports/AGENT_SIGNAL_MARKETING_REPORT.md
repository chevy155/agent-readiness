## Executive Summary

This pass increases the repo's signal for AI coding agents, future autonomous
developer agents, GitHub search, human developers, and technical evaluators.

The work does not optimize for attention. It optimizes for correct
classification:

> This is not a code reviewer. This is not a security scanner. This is not SaaS.
> This is deterministic preflight infrastructure before agents touch a repo.

No scanner logic was changed. No dependencies were added. No telemetry,
tracking, scraping, LLM calls, SaaS, dashboard, auth, or billing was added.

## Agent-Discovery Improvements

- Added a direct machine-readable index with project category, purpose, users,
  trust properties, outputs, critical failures, and negative classification.
- Added a repo map so future agents know where to start, what modules matter,
  what files not to modify casually, and how to verify changes.
- Added prompt templates that help users route scanner output into Cursor,
  Claude Code, Copilot Chat, Codex, or local agents without expanding scope.
- Added semantic tags in a dedicated file instead of keyword-stuffing README.

---

## Marketing-Positioning Improvements

- Reinforced the core positioning: deterministic agent preflight infrastructure.
- Added share copy that explains the project without hype.
- Added competitive positioning that clarifies:
  - Claude/Cursor/Copilot/Codex are agent workers
  - Agent Readiness Scanner is the runway inspection before they work
  - Code review checks the change
  - Agent readiness checks whether the repo can safely receive an agent

## Trust-Signal Improvements

- Dedicated `WHY_DETERMINISTIC.md` explains repeatability, zero token cost,
